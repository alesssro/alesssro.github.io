# Traducciones Alesssro

Web de [Traducciones Alesssro](https://alesssro.github.io/): traducciones al castellano de juegos de PlayStation y PlayStation 2 que nunca llegaron en español.

Los parches se descargan desde las [Releases](https://github.com/alesssro/alesssro.github.io/releases) de este repositorio. Solo se distribuyen parches: necesitas tu propia copia del juego.

¿Te gustan? Pronto podrás apoyar el proyecto con una donación.
