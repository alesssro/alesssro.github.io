# Traducciones Alesssro

Web de [Traducciones Alesssro](https://alesssro.github.io/): traducciones al castellano de videojuegos clásicos de todas las consolas.

Los parches se descargan desde las [Releases](https://github.com/alesssro/alesssro.github.io/releases) de este repositorio. Solo se distribuyen parches: necesitas tu propia copia del juego.

¿Te gustan? ☕ **Ayúdanos a traducir más videojuegos en [Ko-fi](https://ko-fi.com/alesssro).**
